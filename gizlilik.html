Privacy Policy - Shorts Otomasyon

Last updated: October 2026

Shorts Otomasyon is a private, non-commercial tool used only by its owner to upload short videos to the owner's own YouTube channel Zihin Kalesi (@zihinkalesitr). It is not offered to other users.

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

Data we access

The application uses only the YouTube Data API v3 with the scope youtube.upload, solely to upload videos created by the owner to the owner's own channel. It does not read, collect, analyze, store or share any YouTube user data, and it never accesses any other person's account.

Storage and sharing

No personal data is collected, sold or shared with third parties. The OAuth credentials of the owner's account are stored encrypted as private secrets in a private repository, accessible only by the owner.

Revoking access

Access granted to this application can be revoked at any time from the Google security settings page.
