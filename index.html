Shorts Otomasyon

A private, non-commercial tool that prepares short motivational videos and uploads them to its owner's own YouTube channel, Zihin Kalesi (@zihinkalesitr), only after the owner reviews and approves each video.

This application uses YouTube API Services (YouTube Data API v3, videos.insert only).
